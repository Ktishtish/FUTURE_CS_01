# FUTURE_CS_01

## Cyber Security Track

### Web Application Vulnerability Assessment

This repository documents my Cyber Security track project focused on conducting a web application vulnerability assessment in a controlled laboratory environment.

## Objective

The objective of this project is to identify, analyze, document, and communicate common web application security vulnerabilities using industry-relevant security tools and methodologies.

## Tools

- Nmap
- OWASP ZAP
- Browser Developer Tools
- Canva

## Skills Demonstrated

- Network reconnaissance
- Vulnerability analysis
- Risk classification
- Security testing
- Evidence collection
- Security reporting
- Technical-to-business communication
- Remediation recommendations

## Methodology

1. Lab environment setup
2. Reconnaissance
3. Web application mapping
4. Passive security analysis
5. Manual validation
6. Risk classification
7. Remediation analysis
8. Vulnerability reporting

## Project Status

🚧 In Progress

## Scope

Testing will be conducted exclusively against a deliberately vulnerable application within a controlled laboratory environment.

## Disclaimer

This project is conducted for educational and cybersecurity portfolio purposes. Testing is limited to systems that I own or have explicit authorization to assess.
